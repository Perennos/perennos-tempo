# Security policy

This source candidate is not a security certification. Keep the gateway on loopback, use a private OS-owned data folder, and do not place sensitive material in hosted requests. The `TEMPO_HOME` folder is not an OS security boundary.

Do not publish credentials, tokens, private prompts, customer records, or exploit details in a public issue. Check [perennos.com](https://perennos.com) or [perennos.com/tempo](https://perennos.com/tempo) for the current private security-reporting route. If neither page provides one, ask for a private route without disclosing exploit details.

No response-time commitment, supported-version window, or coordinated disclosure deadline is established in this candidate.
